# Nginx como Proxy Reverso com Node.js e MySQL

Desafio prático de orquestração de containers utilizando Docker e Docker Compose.

## Como Executar

Certifique-se de ter o Docker e o Docker Compose instalados em sua máquina. Na raiz do projeto, execute o seguinte comando:

```bash
docker compose up --build
```

Após o carregamento dos containers, abra o seu navegador e acesse:

[http://localhost:8080](http://localhost:8080)

A cada atualização de página (F5), um novo nome será inserido no banco de dados e listado em tela.
